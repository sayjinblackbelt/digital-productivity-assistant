# Interpretação de Dados

## Objetivo

Transformar dados em observações compreensíveis sem inventar conclusões que não sejam sustentadas pelos dados fornecidos.

## Possíveis análises

- maior e menor valor;
- média;
- variação;
- evolução percentual;
- comparação entre períodos;
- tendências;
- valores atípicos;
- indicadores simples.

## Perguntas de contexto

1. O que os dados representam?
2. Qual período está sendo comparado?
3. Qual pergunta o usuário deseja responder?
4. Os dados estão completos?

## Exemplo de evolução

```text
Valor inicial: 100
Valor final: 125

Variação absoluta: +25
Variação percentual: +25%
```

O assistente deve separar claramente:

- cálculo;
- observação;
- interpretação;
- limitações.
