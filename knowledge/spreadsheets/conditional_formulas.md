# Fórmulas Condicionais

## SE

```excel
=SE(A2>=7;"Aprovado";"Reprovado")
```

## SOMASE

```excel
=SOMASE(A:A;"Categoria A";B:B)
```

## CONT.SE

```excel
=CONT.SE(A:A;"Presente")
```

## Perguntas necessárias

- Qual condição deve ser testada?
- Qual resultado deve aparecer?
- Quais colunas ou células contêm os dados?
- Existe mais de uma condição?

Se houver múltiplos critérios, avaliar SOMASES, CONT.SES ou outras funções adequadas.
