# MVP — Perguntas Iniciais

## Objetivo

O MVP utiliza perguntas de triagem para identificar a necessidade do usuário e coletar apenas o contexto necessário.

As perguntas não precisam ser apresentadas rigidamente em todos os atendimentos. Se a mensagem inicial já fornecer informações suficientes, o sistema deve avançar diretamente para a solução ou para perguntas específicas.

## Cinco perguntas-base

### 1. O que você deseja resolver?

Categorias iniciais:

- criar uma fórmula;
- corrigir uma fórmula;
- organizar uma planilha;
- criar ou organizar uma tabela;
- interpretar dados;
- formatar um documento;
- corrigir ou melhorar um texto;
- criar uma resposta ou conteúdo;
- outro problema.

### 2. Qual ferramenta você está utilizando?

- Microsoft Excel;
- Google Sheets;
- LibreOffice Calc;
- Microsoft Word;
- Google Docs;
- LibreOffice Writer;
- outra.

### 3. O que você já tentou fazer?

Essa pergunta ajuda a identificar tentativas anteriores, mensagens de erro e possíveis caminhos já explorados.

### 4. Qual resultado você espera?

O sistema deve compreender o objetivo final, não apenas o sintoma apresentado.

### 5. Você pode fornecer um exemplo?

O usuário pode explicar, fornecer dados fictícios, copiar uma tabela ou, futuramente, enviar um arquivo.

## Princípio

> Perguntar apenas o necessário para produzir uma solução útil.

Se o contexto já estiver completo, o assistente não deve repetir perguntas de triagem.
